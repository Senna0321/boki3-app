# 日商簿記3級 仕訳アプリ・スマホ対応版

HTML / CSS / JavaScriptだけで動く、スマホ対応・PWA対応の簿記3級仕訳アプリです。

## 今回の対応
- 📱 スマホ画面に最適化
- 縦画面でレイアウトが崩れにくい
- 仕訳入力欄をスマホでは縦型カード表示
- ボタンを指で押しやすいサイズに調整
- 問題一覧をスマホ幅で折り返し表示
- 横スクロールを極力なくす設計
- 📲 ホーム画面追加用のPWA設定
- 選択した簿記3級アイコンをアプリ用アイコンとして設定
- 📝 時間制限なし（タイマー完全削除）
- 🗑️ 学習履歴と前回間違えた問題のリセット機能
- 白＋薄いミントグリーンの背景を維持
- 基礎100問・応用100問・本試験レベル100問

## パソコンで確認
index.html をダブルクリック。

## スマホでホーム画面に追加
PWAの「ホーム画面に追加」は、HTTPSで公開したページで利用します。
GitHub Pagesなどで公開した後、スマホのブラウザからURLを開いて「ホーム画面に追加」を選びます。

## WEB公開
このフォルダをそのままGitHub Pagesなどの静的ホスティングにアップロードできます。
